Project Structure

This document outlines the file layout and directory structure for the OTHDecomp (Over The Hedge PS2 decompilation) project.

Directory Overview

.
├── asm/               # Disassembled MIPS assembly split files
├── build/             # Compiled object files, map files, and built binaries
├── docs/              # Project documentation and developer guides
├── include/           # C/C++ header files and structural definitions
├── src/               # Decompiled C/C++ source code and entry assembly
├── tools/             # Helper scripts, extractors, and decompilation utilities
├── .vscode/           # Recommended VSCode extensions and task configurations
├── Makefile           # Main build orchestration script
├── ps2.ld             # Linker script defining memory placement
├── splat.yaml         # Splat disassembly configuration file
└── symbols_addrs.txt  # Global symbol names mapped to memory addresses


Detailed Directory Breakdown

asm/

Contains raw MIPS III assembly split files generated by splat or extracted from the target executable. These serve as the baseline for non-decompiled functions.

asm/cod/: Assembly blocks sorted by memory offset addresses (e.g., entry.s, FUN_003ef9fc.s).

build/

Output directory generated during the compilation process. This directory is typically ignored by version control.

Intermediate target object files (.o).

SLUS_213.ELF: The compiled target executable.

SLUS_213.map: Linker map file containing function address layouts.

docs/

Technical documentation for contributors and reverse engineers.

BUILDING.md: Toolchain setup and compilation instructions.

PROJECT_STRUCTURE.md: Description of project directory organization.

include/

Global and module-specific header files used across the C++ codebase.

types.h: Custom type definitions, primitive aliases, and PS2 EE hardware types.

classes.h: Class structure declarations and vtable interfaces.

src/

The primary C and C++ source code tree containing decompiled functions.

main.cpp: Executable entry point logic.

entry.s: Low-level boot assembly.

classes/: Object-oriented class implementations (e.g., FOO.cpp).

engine/: Core engine infrastructure routines, including asset and resource loaders.

physics/: Engine physics wrappers, including Havok shape definitions.

worldsim/: World simulation, actor systems, and character management.

System & Build Files

Makefile: Drives the compiler toolchain and link step.

ps2.ld: Linker script that maps .text, .data, .rodata, and .bss sections to the PS2 RAM layout.

splat.yaml: Configuration mapping binary splits, file splits, and symbol references for disassembly tools.

symbols_addrs.txt: List of known hardware registers, global variables, and function pointers.
