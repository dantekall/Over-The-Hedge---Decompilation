To get the project, clone the repository with Git: git clone https://github.com/dantekall/Over-The-Hedge---Decompilation. Change into the newly cloned repository directory: cd Over-The-Hedge---Decompilation. From the repository’s root directory, create a folder named build: mkdir build. Start the build by running make from the repository’s root directory. The build process compiles the project using the repository’s Makefile. Let the command finish before checking the output. When the build completes, look in the build folder for the generated SLUS_213.00 file. SLUS_213.00 is the compiled game executable produced by the build. If make reports an error, check that you are in the repository’s root directory and that the build folder exists. You can rerun make from the repository root whenever you want to build again.
